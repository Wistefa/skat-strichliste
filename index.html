📖 Bockrunden-Regeln

Was ist eine Bockrunde?
  • Eine Bockrunde umfasst 4 Spiele (jeder Spieler gibt einmal)
  • In dieser Zeit zählen alle Spielwerte doppelt — Gewinne wie Verluste
Wann wird eine Bockrunde ausgelöst?
  • Der Alleinspieler verliert ein Spiel → automatisch neue Bockrunde
  • Manuell über den Button „+ Bockrunde auslösen"
Stapeln (Stacking)
  • Wird während einer Bockrunde ein weiterer Auslöser getroffen, kommt eine neue Bockrunde in die Warteschlange
  • Nach Ende der laufenden Bockrunde startet automatisch die nächste
Beispiel bei 60 Punkten Spielwert:
  • Normal — Alleinspieler gewinnt: jeder Verlierer zahlt −60
  • Normal — Alleinspieler verliert: Alleinspieler zahlt −60
  • Bock — Alleinspieler gewinnt: jeder Verlierer zahlt −120
  • Bock — Alleinspieler verliert: Alleinspieler zahlt −120
